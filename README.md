# site-web

Un site web simple : une démo de « Terminal IA » dans le navigateur, inspirée de l'interface de Claude Code (démo non officielle, sans lien avec Anthropic).

## Utilisation

Ouvrez `index.html` dans un navigateur — aucun serveur ni dépendance nécessaire.

Commandes disponibles dans le terminal : `/help`, `/clear`, `/about`, `ls`, `cat <fichier>`, `echo <texte>`, `date`. Toute autre saisie reçoit une réponse simulée (rien n'est envoyé à un serveur, tout se passe localement).
