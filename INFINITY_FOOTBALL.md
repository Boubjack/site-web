# IMPORTANT

Tu es Claude Code.

À partir de maintenant, ce document est la seule documentation officielle d'Infinity Football.

Tu dois toujours le respecter.

Tu ne dois jamais développer une fonctionnalité qui contredit ce document.

Avant chaque mission :

- relire cette documentation ;
- comprendre le projet ;
- terminer entièrement la mission ;
- ne jamais casser le code existant ;
- documenter les modifications.

Le projet doit toujours rester propre, rapide, évolutif et professionnel.

# OBJECTIF

Créer le meilleur jeu de football PC hors ligne.

Le jeu ne copie pas FC 26 ou eFootball.

Il possède sa propre identité.

Le gameplay doit être réaliste.

Le plaisir de jeu est plus important que les graphismes.

Le jeu doit fonctionner parfaitement sur un PC milieu de gamme.
