Infinity Football

Un « Football Life Simulator » où le terrain n'est qu'une partie de l'expérience : carrière, monde ouvert, patrimoine, médias, célébrité et héritage forment un seul univers cohérent.

Lancer le prototype Lire le Game Design Document
Ce que contient ce dépôt. Trois choses distinctes, et il est important de ne pas les confondre. D'abord le Game Design Document complet — l'intégralité des tomes transmis, sans résumé ni coupe. Ensuite un prototype jouable dans le navigateur, sans installation ni compilation. Enfin le moteur de simulation complet écrit en TypeScript dans src/ : 21 systèmes, ~27 400 lignes, 35 tests, zéro dépendance — c'est la couche que l'on brancherait sur Unreal ou Unity. Le rendu 3D, les maillages, l'audio échantillonné et le réseau temps réel relèvent d'une production moteur et ne sont pas dans ce dépôt : la matrice de traçabilité dit précisément, chapitre par chapitre, ce qui tourne et ce qui n'y est pas.

Ce qui tourne réellement

⚽

Moteur de match

Simulation minute par minute. Le contrôle du ballon dépend de la technique, de la vitesse, de la pression adverse, de la météo, de la pelouse et de la fatigue. Six arbitres aux personnalités distinctes. Les adversaires apprennent de saison en saison.

🌍

Monde ouvert vivant

20 pays et 20 villes dans le prototype navigateur ; 36 pays, 64 villes et plus de 20 000 lieux générés dans le moteur complet. Les PNJ changent d'emploi, déménagent, vieillissent. Des commerces ouvrent et ferment. Le monde évolue même quand vous ne jouez pas.

💰

Économie et patrimoine

Quatre comptes, journal comptable exhaustif, investissements à risque réel — un placement peut faire faillite. Immobilier, personnel, collections, fondations et succession.

🤖

IA à mémoire

Les commentateurs citent vos anciens clubs, vos records et votre musée. Les journalistes vous renvoient vos déclarations passées. Le monde se souvient.

🏆

Boubjack Awards

Les 17 catégories, le tapis rouge, les 10 temps de la cérémonie, les discours des légendes, le suspense de l'enveloppe. Une ville hôte différente chaque année.

📱

Smartphone complet

21 applications, IA secrétaire qui répond à vos questions sur vos vraies données, réseaux sociaux à commentaires générés, Snapstreak, commandes et livraisons physiques.

Architecture

Principes
  • Modulaire — 21 systèmes indépendants qui ne communiquent que par un bus d'événements typé. Aucun système n'importe un autre système.
  • Déterministe — une graine reproduit exactement le même monde, jusqu'aux titres décernés. Chaque système tire dans son propre flux nommé.
  • Extensible — ajouter une ville, un club ou un véhicule est une simple donnée, sans modification de code.
  • Compatible — sauvegardes versionnées, chaîne de migrations, somme de contrôle : les anciennes parties sont migrées, jamais cassées.
  • Sans dépendance — aucun paquet d'exécution, ni dans le moteur TypeScript ni dans le prototype navigateur.

Le tableau de bord du monde vivant

npm run web démarre un monde unique côté serveur qui avance en continu, que quelqu'un regarde la page ou non — 20 minutes de jeu par seconde réelle. Le tableau de bord affiche en direct la carrière, la ville et sa météo, la une de la presse, le patrimoine, le dernier match avec sa carte de chaleur et ses commentaires, le smartphone, les habitants alentour, les scores de qualité et la console développeur.

Démarrer

Aucune dépendance d'exécution. Le prototype navigateur tourne derrière n'importe quel serveur statique — les modules ES exigent le protocole HTTP, ouvrir le fichier directement ne fonctionnera pas. Le moteur TypeScript demande Node 20 ou plus récent.

# Prototype navigateur
python3 -m http.server 8000        # puis http://localhost:8000
node tests/run.js                  # 75 tests

# Moteur de simulation complet
npm install
npm test                           # 35 tests
npm run simulate                   # une démonstration headless
npm run web                        # tableau de bord sur http://localhost:8080
